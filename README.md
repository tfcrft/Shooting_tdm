# 方块火线：5V5 单机团队战

一款不依赖网络服务或后端的浏览器第一人称方块射击游戏。玩法参考 Bloxd.io 的 Cube Warfare Teams，并针对单机对战实现完整的 5v5 人机系统

## 启动

- 1.在本目录运行 python3 -m http.server 4173，然后访问 http://localhost:4173
- 2.直接打开html

## 操作

- WASD：移动
- Shift：冲刺
- Space：跳跃
- 鼠标：瞄准
- 双击游戏画面：锁定鼠标（Esc 解除并暂停）
- 左键：射击
- 右键：瞄准 / AWP 开镜
- R：换弹
- 1–6：切换六种武器
- 7：选择方块，左键放置临时掩体
- 8：选择战术镐，左键破坏临时方块与木箱
- B：战地强化商店
- 按住 Tab：计分板
- Esc：暂停

## 对局规则

- 红蓝两队各 5 人；玩家选择一队，其余 9 个席位由 AI 填充
- AI 有新兵、轻松、标准、老兵、精英五档，反应、精度、射速、移动和视野均有实质差异
- 单局 5 分钟；率先达到 30 次团队击杀立即获胜，时间结束时分数高者获胜
- 击杀获得 3 枚强化币，可购买生命、速度、护甲三类三级强化
- 含 M1911、MP40、AK-47、M16、双管霰弹枪、AWP 六种枪械
- 每次复活携带 10 个队色方块，可临时建造掩体，并能用战术镐拆除

游戏完全使用原生 HTML、CSS、Canvas 与 Web Audio 编写，无构建步骤、无第三方运行时依赖
